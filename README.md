# Freshservice Academy

A free, self-paced course that takes a complete beginner from **ITSM basics** to working confidently in **Freshservice**: lessons, a practice service desk, interactive tools, hands-on labs for a real Freshservice trial, a capstone project and interview preparation.

Open it here: **https://rk630.github.io/freshservice-academy/**

## Use it like an app

- **iPhone / iPad:** open the link in **Safari** → tap **Share** → **Add to Home Screen**.
- **Android:** open the link in **Chrome** → menu (⋮) → **Add to Home screen** or **Install app**.
- After the first visit it also works **offline**. Reference links to Freshworks' own pages still need internet.
- Progress is saved on each device separately.

## What's inside

- ITSM from zero (no IT background needed)
- Freshservice: tickets, SLAs, routing, service catalog, knowledge, problems, changes, assets/CMDB, automation, Freddy AI, reports
- Practice desk with guided missions
- 14 labs for a Freshservice free trial, with a copy-paste lab kit
- Capstone implementation project, resume guidance and an interview question bank

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole course |
| `manifest.webmanifest` | App name, colours and icons for "Add to Home Screen" |
| `sw.js` | Offline support |
| `icons/` | App icons |
| `.nojekyll` | Tells GitHub Pages to serve files as they are |

## Updating the course

1. Replace `index.html` with the new version (keep the file name).
2. In `sw.js`, change `const VERSION = "fsa-v1";` to `"fsa-v2"` (then v3, and so on).
3. Commit. Phones pick up the update the next time the app is opened online.
